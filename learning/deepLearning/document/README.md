# DeepLearning Core: Native C++ Perceptron

## Overview
This repository contains the foundational implementation of a custom-built, zero-dependency Neural Network Perceptron written entirely in C++17. Designed as an educational and structural prototype, it actively avoids abstracted libraries (like PyTorch or TensorFlow) in favor of raw mathematical state manipulation and memory-safe Object-Oriented Architecture.

## Architecture

### 1. `Key_Concepts` (State Persistence)
The system explicitly tracks the fundamental parameters of machine learning:
- `weight`: The core learning parameter multiplying the input.
- `biases`: The shift parameter to delay activation.
- `forward_pass`: The mathematical "guess" generated by the network.
- `loss_function`: The error differential between the guess and ground truth.

### 2. `data_parser` (Multimodal Unification)
A critical feature of this prototype is its capacity to simulate ingesting raw, multimodal datasets and mathematically flattening them into unified `std::vector<double>` input tensors:
- **Text (`data_txt`)**: Implements a foundational embedding simulation by hashing/summing ASCII string token values.
- **Images (`data_img`)**: Normalizes raw integer pixel arrays (0 to 255) down to a floating-point gradient (0.0 to 1.0) mathematically preventing weight explosion.
- **Video (`data_video`)**: Ingests temporal frame-to-frame pixel deltas representing optical flow.
- **Voice (`data_voice`)**: Ingests normalized 16kHz PCM waveform samples representing true sonic oscillation.
- **Numbers (`data_num`)**: Native tabular pass-through.

### 3. `mind()` (Inference Engine)
The core execution environment where the multimodal `Test_Sample` data is parsed, mapped to the `Input` vector, and prepared for the forward pass dot-product calculation.

## Directory Structure
- `/include/perceptron.hpp`: Defines the core structs and `Perceptron` class signature.
- `/src/perceptron.cpp`: Houses the implementation logic, normalization loops, and state binding.
- `/src/main.cpp`: The primary execution entry point.
- `/test/test_parser.cpp`: Unit tests for verifying the mathematical precision of the `data_parser`.

## Building the Source
The project is built against strict standard compliance (C++17). To compile the raw prototype and verify syntax natively using GCC:
```bash
g++ -fsyntax-only -Wall -Wextra -pedantic -std=c++17 src/perceptron.cpp
```
